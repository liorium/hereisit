## Users

주요 사용자는 별도 프로그램 설치나 가입 없이 이미지와 간단한 데이터 작업을 빠르게 끝내려는 한국어 사용자다. 주로 일회성 또는 일상적인 작업을 위해 현재 브라우저에서 적합한 도구를 찾고, 결과를 확인한 뒤 직접 복사하거나 다운로드한다.

현재 제품은 로그인 없이 사용할 수 있다. 우선 수익 모델은 유용한 무료 도구에 Google AdSense를 연결하는 것이다. 로그인 기반 유료 기능은 후속 선택지이며, 범위·가격·무료 기능의 경계는 아직 결정하지 않았다.

## Product Purpose

HereIsIt은 사용자가 필요한 도구를 빠르게 찾고 파일과 간단한 데이터 작업을 한곳에서 완료하도록 돕는다. 파일로 시작하면 호환되는 도구를 추천하고, 도구를 알고 있다면 검색이나 카탈로그에서 바로 시작할 수 있어야 한다.

성공은 사용자가 파일 처리 위치와 한계를 이해한 상태에서 최소한의 단계로 작업을 끝내고, 검증된 결과를 명시적으로 다운로드하는 것이다.

사업 목표는 운영자가 실시간으로 붙어 있지 않아도 유용한 도구가 안정적으로 동작하고, 검색 유입과 재방문을 통해 광고 수익을 만드는 것이다. 판단 기준은 기능 개수보다 작업 완료율, 검색 유입, 재방문, 운영비를 뺀 수익과 수동 개입 빈도다. 광고 승인·매출·완전 무관리를 보장하지 않는다.

## Revenue and Maintenance Priorities

1. 이미 공개된 도구의 성공률과 속도, 모바일 사용성을 먼저 개선한다. 서버 오류는 실제 원인을 해결하고 가능한 경우 로컬 처리로 작업을 이어간다.
2. 각 주요 도구에 실제 옵션·제약·결과 해석을 설명하는 독자적인 안내를 제공한다. 검색 노출을 위해 중복 페이지나 의미 없는 분량을 늘리지 않는다.
3. AdSense 연결 시 실제 게시자 ID, 사이트 확인, 개인정보 안내와 필요한 동의 설정을 함께 확인한다. 광고 로딩 실패나 광고 차단이 도구 실행·다운로드를 막아서는 안 된다.
4. 광고는 파일 선택·실행·다운로드 버튼과 명확히 구분한다. 클릭 유도, 의도적인 처리 지연, 강제 광고 시청이나 페이지 새로고침을 넣지 않는다.
5. 장애·삭제 실패·예산 초과는 자동 감지하고 조치가 필요한 경우에 알린다. 비용 보호 장치를 유지하면서 정상 사용이 오래 차단되는 문제도 해결한다.

현재 점검 결과와 후속 작업은 `docs/research/2026-09-18-adsense-readiness.md`에서 관리한다.

## Positioning

HereIsIt의 핵심 차별점은 도구 탐색과 명확한 파일 처리 흐름이다. 대부분의 도구는 브라우저에서 처리한다. 이미지 압축은 업로드·삭제 안내가 있는 고성능 서버 처리를 기본값으로 제공하며, 사용자가 내 기기 처리를 선택할 수 있다. 파일을 전송하는 도구는 실행 전에 처리 위치를 알린다.

모든 처리 도구는 버전이 있는 계약, 제한된 자원 사용, 구조화된 진행 상태와 오류를 가진다. 더 큰 결과나 검증되지 않은 결과를 편의를 위해 제공하지 않는다.

## Operating Context

- 홈에서 도구를 검색하거나 파일을 선택해 호환 도구를 추천받는다. 파일 추천은 업로드 없이 제한된 앞부분만 확인한다.
- 도구 화면에서 파일을 선택하고 설정을 조정한 뒤 처리한다. 가능한 작업은 현재 탭의 Worker에서 실행된다.
- 결과는 현재 탭의 메모리에 보관되며 사용자가 다운로드 동작을 선택해야 저장된다.
- 서버 처리는 도구별 안내와 실행 동작을 통해 시작한다. 이미지 압축은 서버 처리가 기본이며 내 기기 처리도 선택할 수 있다. 입력과 결과는 임시 보관 후 확인·만료 절차에 따라 삭제된다.
- 즐겨찾기와 최근 도구에는 도구 ID만 저장하며 파일 내용과 파일명은 저장하지 않는다.

## Capabilities and Constraints

- 현재 이미지 크기 조절, 형식 변환, 압축, 워터마크와 JSON 정리·검사 도구를 제공한다.
- 파일은 가능한 한 업로드하지 않고 기기 안에서 처리한다. 서버 전송은 실행 전에 명확히 고지하고 사용자의 명시적 선택을 요구한다.
- 파일 크기, 페이지 수, 픽셀 수, 메모리, 결과 크기와 처리 시간에는 작업별 상한이 있다. 진행률과 실패는 실제 상태를 과장하지 않아야 한다.
- 파일 내용, 파일명, 썸네일과 서명된 다운로드 URL을 분석 또는 로그에 기록하지 않는다.
- 공개되지 않았거나 검증 게이트를 통과하지 않은 서버 기능을 사용 가능한 기능처럼 안내하지 않는다.
- 현재 공개 인터페이스는 한국어 우선이며 Cloudflare Pages에 정적 Next.js 애플리케이션으로 배포된다.
- 로그인 기반 유료 기능은 계획되어 있으나 인증 방식, 유료 기능 목록, 가격과 출시 시점은 미정이다.

## Brand Commitments

- 제품명은 `HereIsIt`이다.
- 제품 원칙은 “Simple is best”다.
- 사용자 문구는 쉽고 직접적인 한국어를 사용하며, 하나의 추천 경로와 최소한의 화면으로 작업 완료를 돕는다.
- 개인정보 보호, 속도, 접근성, 모바일 사용성을 장식적 복잡성보다 우선한다.
- 파일 처리 위치와 보관 방식은 작업 전에 숨김없이 설명한다.

## Product Principles

1. 이미지 압축의 고지된 서버 기본값을 제외하면 기기 안에서 처리를 우선한다. 업로드는 사용자가 처리 위치를 이해하고 실행한 경우에만 허용한다.
2. 사용자가 도구를 찾고 실행하고 결과를 이해하고 다운로드하는 데 필요하지 않은 화면과 선택지는 추가하지 않는다.
3. 첫 피드백은 빠르게 제공하고, 메모리와 처리량은 제한하며, 진행 상태와 실패 이유를 정직하게 보여준다.
4. 결과의 정확성, 개인정보 보호와 복구 가능성을 기능 수나 시각적 화려함보다 우선한다.
5. 로그인과 유료 기능을 추가하더라도 현재의 명확한 처리 위치 안내와 검증된 실행 경계를 유지한다.

## Accessibility & Inclusion

키보드만으로 탐색·선택·처리·다운로드 흐름을 완료할 수 있어야 한다. 포커스 이동과 복원, 상태 메시지의 보조기술 전달, 충분한 터치 영역과 모바일 레이아웃을 유지한다. 오류와 제한은 전문 용어 대신 사용자가 다음 행동을 알 수 있는 한국어로 설명한다.
