# File privacy

Files are processed in the browser by default. PDF compression uploads only after a structured or mixed
local no-reduction result, the upload/deletion disclosure, and one explicit server button click.

The dedicated PDF queue and qpdf container use opaque object keys. File contents, filenames, thumbnails,
object keys, URLs, and extracted text are excluded from logs and analytics. A server result is exposed only
after browser verification; input and result objects are deleted after acknowledgement or the bounded sweep.
Rewriting a PDF invalidates electronic signatures.

The user-facing Korean policy is maintained in `apps/web/src/app/privacy/page.tsx`.
